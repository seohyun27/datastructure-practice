## 📂 Contents

### Project 1: 정렬과 탐색 기초
- **Selection Sort**: 선택 정렬 구현 및 성능 측정
- **Binary Search**: 이진 탐색 알고리즘 구현 및 성능 측정

### Project 2: 순열 (Permutation)
- 순열 알고리즘 구현 및 성능 측정
- 알고리즘 효율성 개선 작업

### Project 3: 다항식 (Polynomial) - 배열
- 구조체를 활용한 다항식 정의
- 다항식의 덧셈 및 곱셈 연산 구현

### Project 4: 스택과 큐 (Stack & Queue)
- 스택(Stack)과 큐(Queue), 원형 큐(Circular Queue)의 정의 및 구현
- 동적 할당(Dynamic Allocation)을 이용한 스택/큐 구현

### Project 5: 수식 계산 (Expression Evaluation)
- **Postfix/Infix**: 중위 표기법(Infix)의 후위 표기법(Postfix) 변환
- 스택을 활용한 수식 계산기 구현

### Project 6: 연결 리스트 (Linked List)
- 연결 리스트의 기본 연산 구현
- 연결 리스트를 활용한 스택과 큐 구현
- 리스트의 역순(Invert) 및 병합(Merge) 알고리즘

### Project 7: 다항식 - 연결 리스트
- **Circular Linked List**: 원형 연결 리스트와 가용 공간 리스트(Available Space List) 활용
- 연결 리스트 기반의 다항식 덧셈 및 곱셈

### Project 8: 트리 (Tree)
- 트리의 정의 및 기본 연산
- 트리 자동 생성 알고리즘 구현

### Project 9: 이진 탐색 트리 (BST)
- **Binary Search Tree** 정의 및 탐색 구현
- 노드 개수(Count Node), 깊이(Depth), 단말 노드(Leaf) 계산

### Project 10: 그래프 (Graph) - 인접 리스트
- **Adjacency List**: 인접 리스트를 이용한 그래프 구현
- **DFS / BFS**: 깊이 우선 탐색 및 너비 우선 탐색 구현
- DFS를 이용한 신장 트리(Spanning Tree) 구성

### Project 11: 그래프 - 인접 행렬 & 최단 경로
- **Adjacency Matrix**: 인접 행렬을 이용한 그래프 구현
- **Shortest Paths**:
  - 단일 출발점 최단 경로 (Single-Source)
  - 모든 쌍 최단 경로 (All Pairs)

### Project 12: 정렬 알고리즘 심화
- **Sorting Algorithms**: 선택 정렬(Selection), 삽입 정렬(Insertion), 퀵 정렬(Quick) 구현
- 각 정렬 알고리즘의 성능 비교 및 분석
